- 使用宿主机的 MySQL 8.4.3，在临时端口 43316 和独立数据目录运行。Python 3.13 完成锁文件同步，迁移测试逐字段比对三种状态，覆盖重复导入、冲突和部分写入回滚。

- 使用临时 SQLite 库演练停写备份、两次实际 CLI 导入、只读 API 验收和旧版登记库回退。端到端测试以真实 MySQL、Milvus 和模拟模型验证原 ID 检索、同名替换、大小写区分、可用文档计数和删除。
